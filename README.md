### 🔥 About Cyber Pulse

**Cyber Pulse** is a premium, modern and colorful Python deobfuscator specially designed for **pyobfuscator.com** style obfuscated files.

It features a beautiful CLI interface with animations, progress bars and a clean premium look — perfect for Termux users.

---

### ✨ Features

- 🎨 Modern & Colorful UI (using `rich`)
- ⚡ Fast decoding of zlib + base64 + reverse obfuscation
- 🎬 Beautiful 10-second decoding animation
- 📁 Auto saves output as `decoded.py`
- 🔒 Own tool is protected (cannot be decoded by itself)
- 📱 Fully Termux compatible

---

### 📦 Installation

#### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/Decoder.git
cd Decoder
```

#### 2. Install requirements
```bash
pip install -r requirements.txt
```

> **Note:** If `pip` not found, use `pip3` or `python -m pip`

---

### 🚀 Usage

Simply run the tool:

```bash
python run.py
```

#### Menu Options:

| Option | Description                      |
|--------|----------------------------------|
| `1`    | Decode Obfuscated File           |
| `2`    | About Tool                       |
| `3`    | Update Channel                   |
| `0`    | Exit                             |

---

### 📖 How to Decode a File

1. Run the tool → `python run.py`
2. Select option **`1`**
3. Enter the full path of your obfuscated `.py` file  
   Example:
   ```
   /sdcard/Download/main.py
   ```
4. Wait for the beautiful decoding animation (≈ 10 seconds)
5. Decoded file will be saved as **`decoded.py`** in the same folder
